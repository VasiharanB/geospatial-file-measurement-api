Quickstart & SDK Integration

Seamless integration examples in Python, JavaScript/Node.js, and cURL.

1. Python (requests)

Authenticate using standard environment variables.

import os import requests API_KEY = os.environ.get("GFM_API_KEY") BASE_URL = "https://geospatial-measurement-api-9tqz.onrender.com" # Upload and calculate Shapefile ZIP with open("survey.zip", "rb") as f: response = requests.post( f"{BASE_URL}/api/v1/files/", headers={"X-API-Key": API_KEY}, files={"file": ("survey.zip", f, "application/zip")} ) data = response.json() print("Uploaded File ID:", data["id"]) print("Calculated Features:", data["feature_count"])

2. JavaScript / Node.js (fetch)

const fs = require('fs'); const FormData = require('form-data'); const API_KEY = process.env.GFM_API_KEY; const BASE_URL = 'https://geospatial-measurement-api-9tqz.onrender.com'; const form = new FormData(); form.append('file', fs.createReadStream('parcels.kml')); fetch(`${BASE_URL}/api/v1/files/`, { method: 'POST', headers: { 'X-API-Key': API_KEY, ...form.getHeaders() }, body: form }) .then(res => res.json()) .then(data => console.log('File ID:', data.id));

3. cURL (Command Line)

curl -X POST "https://geospatial-measurement-api-9tqz.onrender.com/api/v1/files/" \ -H "X-API-Key: $GFM_API_KEY" \ -F "file=@survey_plots.zip"
